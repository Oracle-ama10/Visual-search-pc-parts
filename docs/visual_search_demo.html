Visual Search Demo — ระบบค้นหาอะไหล่คอมมือสองด้วยรูปภาพ

ต้นแบบสำหรับแสดงการทำงานของ Backend (FastAPI + PostgreSQL/pgvector + OpenCLIP) ยังไม่ได้เชื่อมต่อ

1) เชื่อมต่อระบบ

การค้นหาไม่ต้องเข้าสู่ระบบ แต่การปรับ Threshold และดู Log เป็นฟังก์ชันของผู้ดูแลระบบ (JWT)

2) ค้นหาด้วยภาพ

ลากรูปอะไหล่มาวางที่นี่ หรือคลิกเพื่อเลือกไฟล์
ผลลัพธ์จะแสดงด้านล่าง ถ้าค้นซ้ำหรือปรับ Threshold ผลก่อนหน้าจะเลื่อนไปอยู่ช่อง "ก่อน"

3) Similarity Threshold (Hard Block)

—
ถ้าคะแนนความคล้ายอันดับ 1 ต่ำกว่าค่านี้ ระบบจะตัดผลลัพธ์ทั้งหมดและแจ้งว่าไม่พบรายการที่ตรงกัน

4) ผลการค้นหา: ก่อน / หลัง

ก่อน

ยังไม่มีผลก่อนหน้า

หลัง (ล่าสุด)

เลือกรูปแล้วกด "ค้นหา"
แถบสีฟ้า = คะแนนความคล้าย (Cosine Similarity ช่วง 0.70–1.00) เส้นแดง = ค่า Threshold ที่ใช้ตอนค้นหานั้น
